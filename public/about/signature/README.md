# HTZ signature

Generated from the approved original PNG by `scripts/signature/build_signature.py`
(the drawing is never redrawn: the SVG is the traced outline of the PNG itself).

| File | Content |
|---|---|
| `htz-signature.svg` | Vector outline, white fill, no background (652 × 589 viewBox) |
| `htz-signature.png` | Transparent PNG, white stroke, alpha = original luminance |
| `htz-strokes.json` | Writing gestures (stem, arch, bar, Z): centerlines, per-gesture ink, timing |

The About page renders the signature inline (`src/components/about/HtzSignature.tsx`)
and reveals each gesture through an SVG mask along its centerline.
